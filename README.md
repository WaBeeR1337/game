# Love Quest 💖

Пиксельная веб-игра из 5 мини-испытаний. Пройдёшь все — получишь сертификат
на исполнение одного желания, который можно скачать картинкой.

## Что внутри

| Уровень | Что делать |
|---|---|
| 1. Как хорошо ты меня знаешь | Квиз с вариантами ответа. Ошибся — вопрос повторяется |
| 2. Найди пары | Классическая «память» на 6 пар |
| 3. Собери фразу | Слова перемешаны, нужно выстроить их по порядку |
| 4. Лови сердечки | Аркада на canvas: лови сердечки, не лови бомбы |
| 5. Последняя загадка | Ответ вписывается текстом, после 3 ошибок даётся подсказка |

Прогресс сохраняется в браузере: вкладку можно закрыть и вернуться на том же
уровне.

## Как запустить

```bash
npm install
npm run dev      # откроется http://localhost:5173
```

Сборка для публикации:

```bash
npm run build    # результат в папке dist/
npm run preview  # посмотреть собранную версию
```

## Как подставить свои вопросы

**Всё личное лежит в одном файле — [`src/config.js`](src/config.js).**
Остальной код трогать не нужно.

Что там меняется:

- `playerName` / `authorName` — её имя и твоя подпись на сертификате;
- `intro` — текст приветствия;
- `quiz.questions` — вопросы и варианты. `correct` — номер правильного
  варианта, считая с нуля (`0` — первый вариант, `1` — второй и так далее);
- `memory.icons` — 6 эмодзи для карточек;
- `phrase.text` — фраза, которую нужно собрать (игра перемешает слова сама);
- `catch` — сколько сердечек поймать (`goal`), сколько жизней (`lives`) и
  сколько секунд на уровень (`duration`);
- `riddle` — вопрос, список допустимых ответов и подсказка. Ответ сверяется
  без учёта регистра, лишних пробелов, точек и разницы «е/ё»;
- `prize` — текст сертификата и твоё финальное сообщение.

После правок достаточно пересобрать: `npm run build`.

## Как выложить в интернет

В репозитории есть готовый workflow `.github/workflows/deploy.yml`.
Чтобы он заработал:

1. Слей ветку в `main`.
2. В настройках репозитория: **Settings → Pages → Source → GitHub Actions**.
3. После push игра будет доступна на `https://<username>.github.io/game/`.

Альтернативы без настройки: закинуть папку `dist/` на
[Netlify Drop](https://app.netlify.com/drop) или в Vercel.

## Техническое

- React 18 + Vite, без сторонних UI-библиотек;
- звуки генерируются через WebAudio — ни одного медиафайла в репозитории;
- сертификат рисуется на `<canvas>` и скачивается как PNG;
- шрифты [Press Start 2P](https://fonts.google.com/specimen/Press+Start+2P)
  (заголовки и кнопки) и [Tiny5](https://fonts.google.com/specimen/Tiny5)
  (текст и цифры) — оба под SIL Open Font License, лежат в `public/fonts`,
  поэтому игра работает без интернета;
- вёрстка адаптивная, аркада управляется клавишами (стрелки, A/D) и пальцем.
